# ミセスらしさ（このアプリのブランド定義）

基準は公式サイト https://mrsgreenapple.com/ の見た目。ロゴ・写真・専用フォント（LINE Seed JP, gopher）は
使わない。使うのは配色・書体構成・部品の形だけ。迷ったら公式をヘッドレス Chrome で撮って横に置く。

## 公式から読み取った要素

- **ライムのグラデ** … `linear-gradient(45deg, #A7DA20, #D0F752 62%, #E2FF91 78%)`。ヒーローと強調セクションの地。
- **白の丸角カード** … `border-radius: 10px`、影は `0 2px 3px rgba(0,0,0,.06)` 程度でごく薄い。
- **深緑の文字** … `#002928`。見出しもボタンもこれ。黒は使わない。
- **ボタンは深緑のピル** … `#235D36` 地に白文字、`border-radius: 999px`、「MORE ›」の形。
- **ティールの丸** … `#15C378` の円に白い数字（Schedule の日付）。通し番号やカテゴリラベルに使う。
- **書体** … 英字は Plus Jakarta Sans（見出し 600、大きめ）、日本語は Zen Kaku Gothic New。
  見出しは英字（News / Schedule）で、日本語は小さく添える。
- **NEW タグ** … 黒地に白の極小ラベル。新曲に付ける。
- **明るく、余白広く、要素は少なめ** … 暗いテーマ・明朝・装飾的な影はやらない。

## トークン（`app/globals.css` の `@theme`）

| 名前 | 値 | 役割 |
| --- | --- | --- |
| `deep` | #002928 | 文字、選択状態、濃いボタン |
| `forest` | #235d36 | 主ボタン |
| `green` | #005e3c | 主ボタンのシマー |
| `lime` / `lime-light` | #a7da20 / #e2ff91 | 帯のグラデ、選択チップの文字 |
| `cream` / `mint` | #faffdf / #e7f5cf | セトリ行の薄い帯 |
| `teal` | #15c378 | 番号の丸、カテゴリラベル、フォーカスリング |
| `fog` / `line` | #f4f4f4 / #d1d1d1 | 本体の地、境界線 |
| `dusk` | #5f6b63 | 補助文字（白地でコントラスト 4.5:1 以上） |
| `rouge` | #c4083a | エラー |
| `lilac` / `sky` / `orange` / `aqua` | 公式のカテゴリ色 | 使う場合はアイコンなど点だけ |

## やらないこと

- ダークテーマ、明朝体、テキストシャドウ多重、ガラス質パネル（一度やって「ダサい」と言われた）
- 公式ロゴの模倣、メンバー写真の利用、LINE Seed JP の読み込み
- 緑を文字色に使う（緑は地とアクセント。文字は深緑か白）
- 情報を増やして賑やかにする。白カード＋余白で公式の清潔感を出す
